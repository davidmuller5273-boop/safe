# Safe 使用教程

> 仅存放于仓库 `docs/`，不会作为机器人消息下发。机器人内发 `/help` 或 `/菜单` 只显示**你的角色能用的**命令，并附带按钮面板。

## 1. 角色

| 角色 | 来源 | 能做什么 |
| --- | --- | --- |
| 普通用户 | 任何人 | 查询类命令 / 查询按钮 |
| 群管理员 | `/addgroupadmin` 授权到某群 | 该群的开奖播报订阅、广告、`/say` |
| 超级管理员 | 由开发者添加 | 以上全部 + 推送开关、冠军/亚军码、群管理员管理、`/broadcast` |

不知道自己的 ID / 角色：发 `/whoami`。

## 2. 按钮菜单

发 `/菜单`（或 `/help`、`/start`）→ 帮助文字 + 按钮：

- 普通用户：🎟 查看开奖 · 📊 推送状态 · 🎫 本群订阅
- 群管理员：再加 订阅/取消开奖播报 · ⚙️ 选择彩种 · 📢 广告状态
- 超级管理员：再加 推送开/关 · 冠军6码/7码 · 亚军6码/7码 · 关闭冠军/亚军

已开启的项显示 ✅，点击后面板自动刷新。点击时会重新校验权限，无权限提示「权限不足」。所有按钮都有对应文字命令，命令照常可用。

## 3. 命令

**查询（所有人）**

```text
/开奖 [彩种]        最新开奖（默认本群订阅的彩种，未订阅则全部）
/开奖历史 彩种      最近100期，可翻页
/开奖订阅           本群已订阅的彩种
/pushstatus         本群推送状态
/whoami             我的 ID 与角色
/菜单               按钮菜单
```

群内直接发「开奖」（本群有订阅时）或「双色球历史」这类关键词也可查询。

**推送开关（超级管理员）**

```text
/push on | off      开 / 关本群推送
/broadcast 文本     发给所有已开推送的群
```

**冠军 / 亚军（超级管理员）**

```text
/开启6码  /开启7码          只推冠军6码 / 7码（自动开推送）
/关闭6码  /关闭7码
/开启亚军6码  /开启亚军7码  只推亚军6码 / 7码（不影响冠军）
/关闭亚军6码  /关闭亚军7码
```

进群默认不推送；冠军和亚军互相独立，可同时开。只 `/push on` 而冠军/亚军都没开时不会推送。

**开奖播报（群管理员及以上，仅群内）**

```text
/订阅开奖 [全部|福彩|体彩|六合彩|彩种]    默认全部
/取消订阅开奖 [同上]                     全部 = 清空本群订阅
```

**广告（群管理员及以上）**

```text
/广告前 文本         本群前广告（不带文本 = 清空）
/广告后 文本         本群后广告
/广告前后 前 | 后    一次设置前后（长内容可用单独一行 --- 分隔）
/adstatus            查看本群广告
/resetads group      清除本群广告，回落全局
/say 文本            机器人代发
```

广告与正文合并为**一条**消息发送；某一侧没设置时用全局广告。

**群管理员管理（超级管理员）**

```text
/addgroupadmin 用户ID [群ID]
/removegroupadmin 用户ID [群ID]
/listgroupadmins [群ID]
```

英文别名：`/lottery` `/lotteryhistory` `/lotterysubs` `/lotterysub` `/lotteryunsub` `/menu`。

## 4. 开奖播报

- 彩种：福彩（双色球、福彩3D、七乐彩、快乐8）、体彩（大乐透、排列3、排列5、7星彩）、香港六合彩、澳门六合彩、新澳六合彩。
- 每 5 秒轮询；开奖前 2 分钟到开奖后 45 分钟密集检查，其余时间每 5 分钟兜底一次。只轮询有群订阅的彩种。
- 出现**新一期**且后台该彩种开关为开 → 约 3 秒内推送到已订阅的群，并**自动置顶**。
- **置顶需要机器人是群管理员并有「置顶消息」权限**；没有权限时照常发送，只是不置顶（日志与后台可见）。
- 某彩种第一次被抓到时只记录、不播报（避免一订阅就推旧结果）。
- 播报默认带本群前后广告，可在后台关闭。

## 5. Web 管理后台

- 系统配置：SafeW Token、群 ID。
- 彩票管理 → 彩种管理 / 开奖记录 / **开奖播报**（总开关、每个彩种的播报开关、最新开奖、群订阅、数据源状态、最近播报及置顶结果）。
- 不重新构建前端也能用：浏览器打开 `https://你的域名/admin/lottery-broadcast/ui`，用后台账号登录。
- 开关默认全部**开启**。

## 6. 进程

| 命令 | 作用 |
| --- | --- |
| `safe setup` | 初始化/增量更新表结构与基础 RBAC |
| `safe admin` | 管理 API（默认 :8081） |
| `safe lottery-collector` | 采集热号开奖并入队 |
| `safe safew-bot` | 预测推送 + 命令/按钮 + 开奖播报（轮询、发送、置顶） |

生产环境请设置 `JWT_SECRET`、`DEVELOPER_USER_IDS`，并限制 MySQL/Redis/8081 不对公网开放。
