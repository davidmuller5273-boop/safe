# Safe 使用教程

> 本文档仅存放于仓库 `docs/`，**不会**出现在机器人 UI、不会作为机器人自动消息下发。

## 1. 角色说明

| 角色 | 来源 | 能力 |
| --- | --- | --- |
| developer | 配置/环境变量 `DEVELOPER_USER_IDS`（逗号分隔 SafeW user id） | 全部权限；唯一可添加/移除 **admin** |
| admin | MySQL 表 `bot_admins` | 管理 group_admin；设置全局/群广告；广播；敏感命令 |
| group_admin | MySQL 表 `bot_group_admins`（绑定具体 `chat_id`） | **仅在授权群**内设置该群广告、`/say` 等 |

规则：

1. 只有 **developer** 能 `/addadmin` `/removeadmin`
2. **developer 或 admin** 能 `/addgroupadmin` `/removegroupadmin`
3. group_admin 只能操作自己被授权的群

## 2. 消息前后广告

每条对外业务正文（预测推送、`/say`、`/broadcast`、带广告的回复）都会走：

```text
BuildOutboundText(prefix_ad, body, suffix_ad)
→ 一次 SafeW sendMessage（绝不会拆成三条）
```

拼接规则：跳过空段，非空段之间用空行（`\n\n`）连接；若前后广告皆空，则只发 body。

### 存储

- **全局广告**：`system_configs` 键 `prefix_ad` / `suffix_ad`
- **群广告**：表 `bot_group_ads`（按 `chat_id`）。一旦存在该群记录，则使用记录中的字段（空字符串表示该侧不加广告，不再回落全局）；删除整行记录后才回落全局（可用重新 `/setprefix group` 等管理）。

### 命令

```text
/setprefix [global|group] <文本>
/setsuffix [global|group] <文本>
/clearprefix [global|group]
/clearsuffix [global|group]
/adstatus
/resetads group
```

- 省略 scope 时默认 **group**（当前会话 chat_id）
- `global` 需要 developer 或 admin
- group_admin 只能改自己权限范围内的群

## 3. 常用机器人命令

```text
/help /whoami
/say <文本>
/broadcast <文本>          # developer/admin → 系统配置中的全部群
/addadmin <user_id>
/removeadmin <user_id>
/addgroupadmin <user_id> [chat_id]
/removegroupadmin <user_id> [chat_id]
/listadmins
/listgroupadmins [chat_id]
```

获取自己的 SafeW `user_id`：私聊机器人发 `/whoami`。

## 4. Web 管理后台

1. 配置 SafeW Token 与目标群聊 ID（系统配置页）
2. 管理彩种与开奖记录
3. 默认账号见 README（务必改密）

## 5. 进程

| 命令 | 作用 |
| --- | --- |
| `safe setup` | 初始化/增量更新表结构与基础 RBAC |
| `safe admin` | 管理 API（默认 :8081） |
| `safe lottery-collector` | 采集开奖并入队 |
| `safe safew-bot` | 队列消费 + getUpdates 命令处理 |

生产环境请设置 `JWT_SECRET`、`DEVELOPER_USER_IDS`，并限制 MySQL/Redis/8081 不对公网开放。
